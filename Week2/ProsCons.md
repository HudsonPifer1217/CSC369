# Pros and Cons of New Implementations
## Pandas
### Pros:
 -  Felt framiliar since I've used Pandas before
 -  Easy to find help on the internet
### Cons:
 -  Slower than DuckDB implementation
 -  Had to chunk the data to use

## DuckDB
### Pros:
 -  Ran super fast
 -  Read parquet file without creating python object
### Cons:
 -  SQL was unframiliar but became intuitive

## Polars
### Pros:
 -  The python style querying made sense
 -  Was easy to learn how to implement
### Cons:
 -  Ran the slowest surprisingly
 -  It's possible I made a mistake in my implementatio, but I expected it to be much faster.

## Favorite:
My favorite was DuckDB because it ran the fastest by far. Even though it was unframiliar at first, the SQL syntax made sense the more I played with it.
